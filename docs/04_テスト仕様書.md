## 1. 方針

- 判定と集計の処理は、画面から切り離した状態を持たない関数（`domain/Rules.kt` など）にまとめ、パソコンの JVM で動く単体テストで確かめる（REQ-032）
- データベース（Room）・Android の暗号の部品・現在地の取得・署名の確認のように Android の仕組みが要る処理は、エミュレータか実機で動かす端末上のテストで確かめる
- バックアップの暗号化は、別の実装（Python）で作った見本と同じ結果になることを、単体テストと端末上のテストの両方で確かめる（パソコンと端末、別の実装の間で同じ鍵になることの確認）
- 画面の見た目と操作（並びが動かない・ボタンが重ならない等）を自動で操作するテストは無い。エミュレータで目で確かめ、その結果を3章に書く
- テストのデータはすべて架空のものである（「見本海岸」「見本漁港 北堤防」「メーカーA」など）

## 2. テストの環境

| 種類 | 置き場所 | 実行する場所 | コマンド（Windows） | 備考 |
|---|---|---|---|---|
| 単体テスト | `app/src/test` | パソコンの JVM（JDK 17） | `gradlew.bat testDebugUnitTest` | GitHub Actions（ubuntu-latest）でも、main への push とプルリクエストのたびに `./gradlew testDebugUnitTest` を実行する |
| 端末上のテスト | `app/src/androidTest` | エミュレータか実機（Android 8.0 以降）。確認に使う環境は Pixel 8・API 36 のエミュレータ | `gradlew.bat connectedDebugAndroidTest` | CI では実行しない。実行すると、つないだ端末のアプリのデータが消える |

- 端末上のテストを実行すると、端末に入れていたアプリのデータ（道具・釣行など）が消える。普段使いの端末では実行しない。画面を確かめる前に実行した場合は、[導入・運用手順書](05_導入・運用手順.md) の手順で見本データを入れ直す
- 端末上のテストのうち、データベースのテスト（`RepositoryTest`）はメモリ上の Room を使い、アプリの実際のデータベースには書かない
- `SignatureTest.genuine_google_maps_is_trusted` は、Google マップが入っていない端末では「スキップ」になる。Google の入ったエミュレータ（Google Play か Google APIs のイメージ）で実行する
- `LocationTest` は Android 12（API 31）以降でだけ動き、それより前の端末では「スキップ」になる。テスト用の位置の提供元を使い、実機の GPS には頼らない
- `SampleDataSeeder.seed` はテストではなく、見本データを入れるための道具である。`-e seed true` を付けて実行したときだけ動き、通常のテストでは「スキップ」になる

## 3. テストケース

一覧はテストコードから `scripts/update_test_spec.py` で作る（手で直さない）。「確認すること」は、スクリプトの `TESTS` に書いた説明か、テストの関数のすぐ上のコメントである。「実行の条件」は、テストの中の `assumeTrue` など（条件を満たさなければ「スキップ」）と `@Ignore` を写したものである。
ID は単体テスト・端末上のテストの順に、ファイルのパスの順、ファイルの中で書かれた順に付ける。テストを足すと後ろの ID がずれるため、ID は版ごとの一覧の中での番号として扱い、テストの特定には「クラス.関数」を使う。

一覧には結果を書かない（固定の「合格」を書くと、テストが失敗しても一覧が合格のままになるため）。結果は Gradle の出力（`app/build/test-results`）か、CI の実行記録で確かめる。

## 6. 文書の検査

| 検査 | コマンド | 合格の条件 |
|---|---|---|
| テスト仕様書の一覧が最新であること | `python3 scripts/update_test_spec.py --check` | 「最新です」と出る（終了コード 0） |

GitHub Actions では、単体テストの後にこの検査を実行する。テストを足した・名前を変えたときは、スクリプトの `TESTS` に説明を足してから `--check` を付けずに実行し、一覧を作り直す。`TESTS` に無いテストや、テストコードに無い項目が残っていると、スクリプトは止まる。
